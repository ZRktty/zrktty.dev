## Location check ⚠️ BLOCKER

| Location listed in JD | Covers Las Palmas? |
|------------------------|-------------------|
| Lisbon, Portugal | ❌ Requires relocation |

| Ireland Remote | ❌ Must be based in Ireland |
| Portugal Remote | ❌ Must be in Portugal (Canary Islands = Spain) |
| United Kingdom Remote | ❌ Must be in UK |

Las Palmas is in Spain (Canary Islands) — not covered by "Portugal Remote". Same timezone as Lisbon (WET/WEST), which could be used as a negotiation angle, but Spain is a different legal entity for payroll/compliance purposes.

**Options:**
- Apply and address the location upfront in the cover letter (same timezone as Lisbon, EU citizen, etc.)
- Skip if you need guaranteed remote-from-Spain

## Summary

SoSafe is a well-funded, mission-driven scale-up with a clear product. The tech stack is a strong match on React/TS, design systems, and AI tooling. Two significant gaps:

1. **Testing** — heavily emphasized in the JD, weak on current portfolio. Would need to lean on testing experience from previous roles explicitly.
2. **Location** — the biggest blocker. Spain is not listed. Las Palmas is not Portugal. Worth applying only if you're comfortable addressing this directly and/or willing to relocate if needed.

The Glassdoor score (3.3/5) and leadership sentiment are below average for a scale-up — worth factoring into your decision.

**Proceed to CV?** Yes, if you have meaningful testing experience in past roles to surface, and are comfortable raising the location question in the cover letter.
