# LinkedIn Banner Design Brief — Zoltan Rakottyai

## Goal

Create a modern, professional LinkedIn banner for a senior fullstack/product engineer.

The banner should communicate:

- calm technical confidence
- product engineering mindset
- system thinking
- modern SaaS aesthetics
- trustworthiness
- startup/product-builder energy

Avoid generic “developer” aesthetics.

The banner should feel closer to:

- Vercel
- Stripe
- Linear
- Raycast

NOT:

- crypto bro
- hacker/matrix
- gaming
- flashy AI gimmicks
- overengineered portfolio visuals

---

# Banner Specs

Canvas size:
1584 × 396 px

Important:
LinkedIn profile photo overlaps the lower-left area.

Keep all critical text:

- center
- center-right
- upper-right

---

# Positioning

Main identity:

## Product Engineer

NOT:

- frontend developer
- fullstack ninja
- software wizard

The banner should communicate:

> "I design and build scalable digital products."

# Visual Direction

## Overall Style

Minimalistic dark SaaS/product engineering aesthetic.

Elegant.
